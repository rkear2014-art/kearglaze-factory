KEARGLAZE FACTORY – shop floor app
==================================

What it does
  Jobs board, job sheets, unit labels (A4 Avery L7165 or 100 x 50 mm),
  glass / spacer / Georgian cutting lists and lead marking sheets.

Using it on the Android tablet (recommended)
  1. Open the web link in Chrome.
  2. Tap "Install app" in the top bar (or Chrome menu ⋮ -> "Add to Home screen").
  3. Open it from the home screen icon. It works without internet once installed.

Using it from this folder instead
  Double-click index.html to open it in Chrome or Edge. Everything works,
  except that it will not install as an app or work offline from a folder.
  Note: data opened from a folder is stored separately from the installed app.

Your data
  Jobs are saved on this device only, inside the browser.
  Clearing Chrome's site data, or uninstalling the app, deletes them.

BACK UP EVERY WEEK
  Settings (⚙) -> "Export all data". Keep the .json file somewhere safe
  (email it to yourself or save it to Google Drive).
  To restore: Settings -> "Import backup file", then choose Merge or Replace.
  The app shows a yellow reminder if there has been no backup for 7 days.

Printing labels
  Print at 100% / Actual size, margins None, headers and footers off.
